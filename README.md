# NRCEP Guide Malaysia — GitHub Pages

A one-page independent NRCEP information and quick-access guide.

## Before publishing

Replace `YOUR-USERNAME` in:
- `index.html`
- `robots.txt`
- `sitemap.xml`

with your GitHub username.

## GitHub Pages

1. Create a repository, e.g. `nrcep-guide`.
2. Upload all files in this folder.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
